# 课程记录含义

campus.name是校区展示名而非学校稳定身份，campus.region是校区所在地区。event_id为稳定观看事件键，seconds是整数秒。现有SCHEMA对应唯一写格式，未知字段、缺失字段与空值均拒绝；这不是对未来演进方式的规定。

字段含义由课程数据提供者声明，不可从名字相似度推断。演进声明可以确认某个嵌套字段的含义延续、默认值与生效版本；旧名重新用于新含义时，两者不因此相同。默认值只作用于未提供字段的旧记录，不自动替换显式NULL。消费者以已登记的表版本和字段含义提出读取请求。

安全数值扩大以所有源值可无损表示为边界，整数不能因为容器类型足够大就经过浮点而丢失精度。源值违反目标声明要保留输入定位信息。课程地区观看次数和时长仍以有效事件为粒度，不因字段路径变更增加事件。
